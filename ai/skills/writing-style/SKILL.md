# Writing style

Loaded through the pointer `.claude/skills/writing-style/SKILL.md`, which holds the skill's name and description. Paths are relative to the repository root.

Read `input/writing-style.md` and write every draft in the voice it describes: tone, sentence length, vocabulary, and anything it says to avoid.

If `input/writing-style.md` is missing or still the unfilled template from `resources/templates/writing_style_template.md`, tell the user and write in a plain, direct, professional voice until they fill it in.
